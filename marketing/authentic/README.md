# Straightforward demo alternative

This version responds to feedback that the narrated slide video felt too AI-generated. It uses a plain local console view and an actual new CLI invocation, with stdout/stderr streamed directly from the child process and the resulting JSON file shown afterward. No output is invented or typed from a script. The browser view is a recording wrapper, not a new product UI or a native operating-system terminal.

Final file: marketing/assets/straight-demo.mp4. The old narrated version is retained. This alternative has no synthetic narration, music, animated marketing slides or fabricated personal story. For natural speech, record your own voice using VOICEOVER.md. A user's voice cannot be supplied without a real recording; do not impersonate the user.

actual-run.json preserves the fixed anonymous command, event timing, process exit, stdout/stderr and public snapshot. The CLI was built immediately before recording. The backend listens only on loopback, accepts only a fixed public read-only command once, and accepts no arbitrary command arguments from the browser. It is a local recording utility, not a service to deploy publicly.

The complete run is retained in the recording, including the actual wait for GitHub. It has not been sped up or cut to imply instant collection. No API request uses a stored token. No LinkedIn post or website replacement is performed by creating this alternative.
